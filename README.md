# Rando
Android : le GPS ne fonctionne que si la page est servie en HTTPS. Déposez le fichier sur un hébergement gratuit (GitHub Pages ou Netlify), ouvrez l’adresse dans Chrome, autorisez la localisation, puis choisissez « Ajouter à l’écran d’accueil ». C’est une page web et non un fichier APK. Elle se lance ensuite comme une application.
